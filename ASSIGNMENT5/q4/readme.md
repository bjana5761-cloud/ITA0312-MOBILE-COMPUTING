# Q4 — Applications of Mobile IP and Routing Requirements

The emergency/healthcare application uses Mobile IP for session continuity. The design recommends a regional/redundant Home Agent, fast handover, reverse tunnelling with IPsec and a second network for backup.

Evaluation from the assignment: session continuity 5/5, delay 4/5, interruption 3/5 improved to 4/5, overhead 4/5, security 4/5, scalability 4/5; overall 4/5 with enhancements.
