# A4 — Local vs Cloud vs Hybrid Processing

Six classes are compared: tiny on-device image classification, cloud speech recognition, peer-to-peer file sharing, end-to-end encrypted messaging, real-time multiplayer state synchronisation and large-scale offline map rendering.

Local is favoured where latency, privacy and offline operation dominate. Cloud is useful for models/data too large for the phone. Hybrid is required where a server must provide authoritative ordering or global state while the device supplies responsive local behaviour.
