# Q7 — Diagnose, Redesign, Validate

The Day-4 design challenge evaluates the original access design for a large population of low-rate sensors, identifies wasted dedicated capacity and redesigns it as a shared access pool with contention-based reservation.

The report's validation records delivered/lost reports, idle reserved-slot share, signalling messages, collisions and delay across device counts. It also sweeps pool size to show the trade-off between collision probability, idle capacity and delay.
