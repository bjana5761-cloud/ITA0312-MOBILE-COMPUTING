# Q3 — CDMA: Orthogonality, Spreading and Near-Far Problem

Walsh codes are orthogonal when synchronised. Timing offsets destroy perfect orthogonality. Power inequality amplifies leakage, creating the near-far problem. The report uses processing gain 10log10(L), BER sweeps and power-ratio sweeps.

Key reported result: at L=64, K=8, BER rises from about 0.009 at equal power to 0.037 at +10 dB and 0.259 at +20 dB for the desired user in the near-far experiment.
