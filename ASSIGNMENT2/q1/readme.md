# Q1 — Mobile Communication or Mobile Computing?

Five cases are classified using mobility, wireless link, disconnection tolerance, context awareness and device-resource limits. The hardest case, the offline meter-reading tablet, is tested with store-and-forward simulation.

The report compares immediate transmission with queued transmission at 90%, 60% and 30% link availability. At 60% availability, immediate delivery loses about 39% while store-and-forward loses essentially none, at the cost of delay and finite buffer storage.
