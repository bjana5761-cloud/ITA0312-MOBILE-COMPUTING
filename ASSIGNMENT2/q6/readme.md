# Q6 — Choosing Multiple-Access Techniques for Real Deployments

Four deployments are scored with weighted criteria: D1 cellular voice, D2 jam-resistant tactical link, D3 high-rate stadium downlink and D4 5,000 low-rate sensors.

Reported winners:
- D1: FDMA, score 3.90; hybrid FDMA + TDMA.
- D2: CDMA, score 3.60; hybrid CDMA + frequency hopping + TDMA traffic slots.
- D3: OFDMA, score 4.10; hybrid OFDMA + time-domain scheduling + SDMA.
- D4: OFDMA, score 3.45; narrow OFDMA/FDMA sub-band + shared reservation pool.
